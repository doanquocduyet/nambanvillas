# Số liệu Facebook Page — chưa đọc được

Thử đọc ngày 2026-09-09 nhưng token thiếu quyền `pages_read_engagement`.

Cách mở: vào https://developers.facebook.com/tools/explorer/ → chọn Page Nam Ban Villas → Permissions → tick `pages_read_engagement` và `pages_manage_engagement` → Generate Access Token → dán token mới vào secret `FB_PAGE_TOKEN`.

Cùng một token đó cũng mở luôn việc tự động comment link dưới bài.
